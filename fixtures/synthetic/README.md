# 合成测试夹具（synthetic fixtures）

> **本目录下全部内容为 synthetic（合成/伪造）数据，不是任何真实用户素材，也不含任何真实个人信息。**
> 用途：让二次开发者在**没有私有素材、没有模型权重、没有 GPU**的情况下，也能跑通结构性回归测试。

## 文件

| 文件 | 用途 |
|---|---|
| `synthetic_six_segment_state.json` | 六段状态的字段模式（schema）示例，展示 6 槽文本、video_refs、execution 游标的结构 |
| `synthetic_ref2va_prompt_template.txt` | 官方 REF2VA 结构化提示词的**中性占位模板**（只保留字段名与 `<Picture N>` 占位符，无任何真实人物/场景描述） |

> 曾经的 `synthetic_min_director_workflow.json` 本身是一套**可导入工作流**，按"只发布一套工作流"的
> 口径已移出公开包（测试改为断言其缺席）。本目录现在只有**非工作流**夹具。

## 为什么需要它们

- 真实工作流的六段文本、参考素材与提示词都属于用户个人创作内容，**不能**随公开仓库发布。
- 但二次开发者仍然需要验证「六段状态机的字段是否完整」「工作流能否加载」「默认态是否中性」。
- 因此这里提供**字段结构一致、内容中性**的合成夹具：结构可测，内容无隐私。

## 用法

```bat
python tests/test_workflow_structure.py
```

测试会断言：
1. `workflows/` 下只有唯一公开工作流，且含中文导演台入口 `H3OperationSelector`
2. 六段状态回到中性默认（文本为空、`h3_prebake_story_id` 为空）
3. 工作流内无私有绝对路径残留
4. 合成字段夹具本身合法且为中性占位；可导入的合成工作流夹具**不在**公开包内

## 明确不做

- 不提供任何真实图片/视频/音频（哪怕"看起来无害"）
- 不提供任何真实剧情文本
- 不触发任何 GPU 生成
